## profile.py — Карточка студента
 
### Проверки
 
| Входные данные | Ожидаемый результат |
|---|---|
| возраст 17 | возраст через 4 года → 21 |
| подготовка 10.5 ч/нед | за 4 недели → 42.00 ч; в день → 1.50 ч |
| подготовка 0 ч/нед | за 4 недели → 0.00 ч; в день → 0.00 ч |

```
Фамилия: Ваньшев
```

```
Подготовка за 4 недели:  42.00 ч
```

## workload.py — Учебная нагрузка
 
### Проверка из условия
Ввод: 3 занятия по 90 мин + 2 занятия по 45 мин, доступно 10 ч
 
| Показатель | Ожидание | Факт |
|---|---|---|
| Нагрузка по предмету 1 | 270 мин | 270 мин |
| Нагрузка по предмету 2 | 90 мин | 90 мин |
| Итого | 360 мин = 6.00 ч | ✓ |
| Свободное время | 4.00 ч | ✓ |
| За 4 недели | 24.00 ч | ✓ |
 
### Граничная проверка: 0 занятий по обоим предметам
Ввод: 0 занятий по каждому, доступно 5 ч → нагрузка 0 мин = 0.00 ч, свободно 5.00 ч.

## variant.py — Художественная мастерская (Вариант 4)
 
### Пример заказа (ручной расчёт)
 
| Позиция | Кол-во | Цена | Стоимость |
|---|---|---|---|
| Альбомы | 3 | 12.50 | 37.50 |
| Наборы кистей | 2 | 20.00 | 40.00 |
 
- Товары без доставки: 37.50 + 40.00 = **77.50 руб.**
- Доставка: **10.00 руб.**
- Итого с доставкой: **87.50 руб.**
- Итого единиц: **5**
- Внесено: 100.00 руб. → Сдача: **12.50 руб.**
### Дополнительные проверки
 
| Случай | Ввод | Ожидание |
|---|---|---|
| Нулевое кол-во позиции 1 | qty1=0, price1=12.50 | стоимость позиции 1 = 0.00 |
| Нулевая доставка | delivery=0 | итого = товары |
| Точная оплата | paid = grand_total | сдача = 0.00 |
| Названия из нескольких слов | «Акварельные альбомы А3» | отображается корректно |
